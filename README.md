# esun-antifraud-competition

> **玉山金融科技公開挑戰賽：詐騙帳戶早期預警系統競賽**

包含參加玉山金融科技挑戰賽──詐騙帳戶預警偵測的完整解決方案。核心目標在於應對真實風控場景中高度變動的詐騙帳戶金流模式。

---

## 📌 競賽內容 (Competition Content)

* **核心任務**：利用銀行端提供的交易紀錄、帳戶基礎屬性等多維度數據，建立高效的演算法模型，精準預警並識別潛在的詐騙、警示帳戶。
* **主要挑戰**：
  1. **真實世界的「概念漂移（Concept Drift）」**：犯罪集團會不斷動態改變其洗錢與轉帳策略，導致傳統靜態特徵或單一時序模型極易失效（如線下驗證高達 0.7，線上測試集卻驟降至 0.002 的極端斷層）。
  2. **高度不平衡數據**：詐騙警示帳戶在全體銀行客戶中佔比極低，具有高度的類別不平衡性，極度考驗模型特徵工程與穩健性。

---

## 🚀 方法概述 (Methodology Overview)

為了解決效能斷層與概念漂移，本團隊經歷了**三次核心方法論的迭代演進**。本儲存庫之核心建模檔案已將前兩階段的失效反思與探索轉化為養分，**完全聚焦並整合至最終階段的自適應風控 Pipeline**：

1. **階段一：時序模型探索**
   * *實作內容*：初步建立常規的時間序列特徵與統計行為指標。
   * *瓶頸*：經數據深入分析後發現，**多數正常客戶在資料集中僅存在一筆或極少次的交易紀錄，導致時序模型因樣本特徵極度稀疏而失效**；同時模型亦無法應對隱藏測試集的動態策略轉移，暴露出嚴重的概念漂移痛點。
2. **階段二：二階段圖論拓撲**
   * *實作內容*：將交易網絡圖形化，引入**圖論拓撲（Graph Topology）**關係，捕捉帳戶間的關聯網路與資金流向。
   * *優勢*：將風控維度提升至網絡層面，即便詐騙帳戶改變個體行為，其資金鏈結的拓撲結構仍具備高辨識度。
   * *瓶頸*：此嘗試雖在線下驗證取得突破，但效果有限，但推測圖拓撲特徵過於間接。跨時間盲測時，犯罪集團會頻繁更換人頭戶使舊資金鏈斷裂，導致間接特徵失去因果關係，因此嘗試以帳戶層級為中心做特徵提取。
3. **階段三：高維個體行為**
   * *實作內容*：回歸個體微觀行為，提取帳戶層級統計特徵。具體涵蓋 7 天交易速度、交易時間間隔標準差、中繼站集中度與環境交互機率矩陣四大方向。
   * *成果*：成功建立能夠從變動中抓出規律的風控模型，有效緩解驗證集與隱藏測試集的極端效能斷層。
